# In the kitchen

Ambient lo-fi restaurant kitchen scenes for long-form video: a ramen shop on a rainy night, a diner on a Sunday morning, a bistro on a busy evening, and a bakery before a snowy dawn.

Everything is a single page, `index.html`. The art is drawn on a canvas, the kitchen sounds are synthesized with the Web Audio API, and the music is generated live with Tone.js (loaded from cdnjs). There are no image or audio files.

## Controls

- **Begin** starts the sound (browsers need a click first).
- **H** hides and shows the controls for clean recording.
- **1 to 4** switch kitchens with a crossfade.
- **M** mutes, **F** goes fullscreen, **Home** in the mixer returns to the start screen.
